Canadian COVID-19 Data Archive: Data Explorer

About the Data Explorer

This is the searchable catalogue for the Canadian COVID-19 Data Archive, a historical collection of Canadian COVID-19 datasets, documents, and webpages spanning March 2020 to January 2024. Automated daily archiving concluded January 31, 2024.

Using the explorer: Browse the tree to choose a dataset and display its archived files. Use the searchable dataset table below to find datasets, inspect their metadata, or jump directly to a file list.

Downloads: Open individual files from a selected dataset, download all files for that dataset as a ZIP, or access its JSON or CSV index. For archive-wide access, use the complete SQLite file index.

How to use the complete SQLite index

Open index.db with the SQLite command-line tool, a desktop SQLite browser, or a programming language with SQLite support. It contains one table, archive, with one row per indexed file. In the query below, replace the example value with the UUID displayed after selecting a dataset, or find it by expanding a row in the searchable catalogue. The file_duplicate = 0 condition excludes duplicate snapshots. 

SELECT uuid, file_name, file_date
FROM archive
WHERE uuid = 'your-dataset-uuid'
  AND file_duplicate = 0
ORDER BY file_date;

Download a result by substituting its uuid and file_name into this URL pattern: https://archive.org/download/cc19da_{uuid}/cc19da_{uuid}.zip/{file_name}
