# Canadian COVID-19 Data Archive: Data Explorer

The [Data Explorer](https://ccodwg.github.io/Covid19CanadaArchive-data-explorer/) is a searchable catalogue for the [Canadian COVID-19 Data Archive](https://github.com/ccodwg/Covid19CanadaArchive). The Archive is a historical collection of Canadian COVID-19 datasets, documents, and webpages; automated daily archiving concluded January 31, 2024.

Archived files are hosted in the Internet Archive's [Canadian COVID-19 Data Archive collection](https://archive.org/details/canadian-covid-19-data-archive). See the main Archive repository for detailed documentation and access options.
